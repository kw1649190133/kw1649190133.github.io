DOM转视频生成工具

简介

仓库地址：【https://github.com/kw1649190133/DOMtoVideo 】

拿已有的重建正射影像（DOM）+ 一条 QGIS 画的航线，反向”演”出一段无人机第一视角巡检视频。

这是个逆向生成工具。正常流程是「飞机拍照 → 重建出 DOM」，这里反着来：「已有 DOM + 假想航线 → 生成模拟实机画面」。

为什么要这么干：平台侧的视频贴地投影、实时扫描特效这类功能需要真实感的视频素材做联调和演示，但等一次真实航飞的成本太高。有 DOM 就能凭空造出任意航线、任意速度、任意帧率的视频，而且每一帧的经纬度、航向、时间戳都是已知真值——这对做投影校验反而比真实视频更好用。

模块 职责 关键类/函数 对外依赖

cli.py 分步调试入口 interpolate / clip / make-video / export-vectors 上述三者
run_mission.py 一键编排 + 工程化外壳 main / load_config / rm_tree 上述全部

分步运行模型

–mode 执行步骤 耗时 用在什么时候
full（默认） 插帧 → 矢量 → 截帧 → 合成 小时级 首次生成
vectors 插帧 → 矢量 秒级 只要拍摄点/覆盖范围，或先备好航点
video 复用 waypoints → 矢量 → 截帧 → 合成 小时级 换影像 / 调视场参数重出片

插帧只花几秒但截帧要几小时，换一张影像重跑没必要重新插帧。而矢量（拍摄点、覆盖范围）跟影像完全无关，可以在渲染还没开始时就先拿到手扔进 QGIS 检查航线合不合理——发现航线画错了能省下几小时的白跑。

注意事项

  1. 开始做影像前可以先生成矢量试试看，避免生成错误的照片，占用过长时间。
  2. 截取范围超过了DOM的像素范围，会截取到黑边。
  3. 可适当调整截取范围的长宽、分辨率， 避免黑边和重叠率过高。
  4. 重复执行指令，会覆盖原有文件，记得妥善保存数据。
